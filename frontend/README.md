# Connections Solver Frontend

A Next.js frontend application for the Connections Solver AI.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Sends POST request to the Connections Solver API
- Displays ranked solutions with scores
- Shows grouped words in an organized layout
- Modern, responsive UI

## API Endpoint

The app sends requests to:
`https://ssm03-connections-solver-ai.hf.space/solve`

## Build for Production

```bash
npm run build
npm start
```
